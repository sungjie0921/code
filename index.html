📊 第一章：生物統計概論

認識生物統計在護理研究中的角色，掌握母體、樣本、參數與統計量的核心概念。

為什麼護理研究需要統計？
🔍 循證醫學基礎用數據說話，讓護理決策有科學根據，而非僅憑經驗。
📈 評估介入效果量化新護理措施的療效，確認是否真正改善病人結果。
📖 閱讀研究文獻看懂期刊中的統計結果，能批判性評估研究品質。
⚖️ 臨床決策支持利用統計資料協助制定個別化、有根據的照護計畫。
核心概念：母體 vs 樣本
概念定義護理例子常用符號
母體 Population 研究所關注的所有個體 全台灣所有糖尿病患者 N
樣本 Sample 從母體中抽取的部分個體 某醫院 200 位糖尿病患者 n
參數 Parameter 描述母體的數值（通常未知） 全台灣糖尿病患者的平均血糖 μ、σ
統計量 Statistic 描述樣本的數值（可由資料計算） 200 位患者的平均血糖值 x̄、s
💡 關鍵記憶法 母體用「希臘字母」（μ、σ、π）；樣本用「英文字母」（x̄、s、p̂）
統計的兩大分支
📋 描述統計 Descriptive
  • 整理、摘要、呈現資料
  • 平均值、標準差
  • 長條圖、直方圖
  • 不做推論，只描述現有資料
第三章主題
🔮 推論統計 Inferential
  • 用樣本推估母體
  • 假設檢定（t、F、χ²）
  • 信賴區間
  • 需考慮抽樣誤差

🏥 護理實例 研究問題：「新的疼痛管理措施是否比傳統方法更有效？」→ 收集疼痛評分資料 → 用 t 檢定比較兩組平均 → 若 p < 0.05 則結論：新措施顯著有效。

📁 第二章：資料種類與測量尺度

辨識資料型態是選擇正確統計方法的第一步。四種測量尺度決定了可以使用哪些統計方法。

兩大資料型態
類別資料 Categorical
名目資料 Nominal 無順序，只有分類
例：血型、性別、種族
次序資料 Ordinal 有順序，但間距不等
例：疼痛等級、教育程度
連續資料 Continuous
區間資料 Interval 等距，但無真正零點
例：攝氏體溫、IQ 分數
比例資料 Ratio 等距，且有真正零點
例：體重、身高、血壓
四種測量尺度詳細比較
尺度有分類有順序等距真零點適用統計
名目 Nominal ✓ ✗ ✗ ✗ 次數、百分比、卡方檢定
次序 Ordinal ✓ ✓ ✗ ✗ 中位數、Spearman 相關
區間 Interval ✓ ✓ ✓ ✗ 平均數、t 檢定、ANOVA
比例 Ratio ✓ ✓ ✓ ✓ 幾何平均、所有統計方法
💡 記憶原則 測量尺度層級越高（名目 → 次序 → 區間 → 比例），可使用的統計方法越多、分析越精細。

⚠️ 常見陷阱：體溫為何是「區間」而非「比例」？ 攝氏 0°C 並非代表「沒有溫度」（真正的零度是 -273.15°C），所以不能說 40°C 是 20°C 的「兩倍熱」。這就是為什麼體溫是區間尺度而非比例尺度。
